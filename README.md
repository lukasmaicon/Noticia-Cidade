# Notícia Cidade 

Este projeto é um portal de notícias clássico desenvolvido para consolidar conhecimentos fundamentais de estruturação web e interatividade. Ele combina um layout de grid tradicional com recursos modernos de navegação e exibição de mídia.

## 🔗 Demonstração
Visualize o projeto online: [https://lukasmaicon.github.io/Noticia-Cidade/](https://lukasmaicon.github.io/Noticia-Cidade/)

## 🛠️ Tecnologias Utilizadas
*   **HTML5**: Estruturação semântica para um portal de notícias com múltiplas seções.
*   **CSS3 (Media Queries)**: Design responsivo garantindo que a notícia chegue com qualidade tanto no desktop quanto no mobile.
*   **JavaScript (Vanilla)**: Lógica para o menu mobile, permitindo a alternância dinâmica de estados e ícones.
*   **jQuery**: Implementação de uma galeria de imagens interativa na seção final do portal.

## 🌟 Destaques do Projeto
*   **Interatividade no Menu**: Uso de JavaScript para criar uma experiência de navegação fluida em dispositivos móveis.
*   **Galeria de Imagens**: Inclusão de uma seção visual dinâmica utilizando a biblioteca jQuery, enriquecendo o layout informativo.
*   **Responsividade**: Layout totalmente adaptável via Media Queries, priorizando a leitura em telas menores.
*   **Projeto de Base**: Um marco importante no meu portfólio que demonstra o domínio de fundamentos essenciais e o uso de bibliotecas externas.

# Notícia Cidade 

This is a classic news portal project developed to consolidate fundamental web structuring and interactivity knowledge. It combines a traditional grid layout with modern navigation and media display features.

## 🔗 Live Demo
View the project live: [https://lukasmaicon.github.io/Noticia-Cidade/](https://lukasmaicon.github.io/Noticia-Cidade/)

## 🛠️ Technologies Used
*   **HTML5**: Semantic structuring for a multi-section news portal.
*   **CSS3 (Media Queries)**: Responsive design ensuring high-quality news delivery on both desktop and mobile.
*   **JavaScript (Vanilla)**: Logic for the mobile menu, allowing dynamic toggling of states and icons.
*   **jQuery**: Implementation of an interactive image gallery in the final section of the portal.

## 🌟 Project Highlights
*   **Menu Interactivity**: Using JavaScript to create a fluid navigation experience on mobile devices.
*   **Image Gallery**: Inclusion of a dynamic visual section using the jQuery library, enriching the informative layout.
*   **Responsiveness**: Fully adaptable layout via Media Queries, prioritizing readability on smaller screens.
