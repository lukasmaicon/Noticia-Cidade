# Notícia Cidade

---

### 🇧🇷 Português

O **Notícia Cidade** é um portal de notícias clássico desenvolvido para consolidar conhecimentos fundamentais de estruturação web e interatividade. Ele combina um layout de grid tradicional com recursos modernos de navigation e exibição de mídia.

Visualize o projeto online: [https://lukasmaicon.github.io/Noticia-Cidade/](https://lukasmaicon.github.io/Noticia-Cidade/)

### Desenvolvimento com Interatividade

Este projeto é desenvolvido com foco em boas práticas de design responsivo e manipulação de elementos dinâmicos. Utilizo estas estratégias para:

* **Interatividade no Menu:** Uso de JavaScript para criar uma experiência de navegação fluida em dispositivos móveis.
* **Galeria de Imagens:** Inclusão de uma seção visual dinâmica utilizando a biblioteca jQuery, enriquecendo o layout informativo.
* **Responsividade:** Layout totalmente adaptável via Media Queries, priorizando a leitura em telas menores.

### Tecnologias

* HTML5 (Estruturação semântica)
* CSS3 (Media Queries)
* JavaScript (Vanilla)
* jQuery (Galeria interativa)
* GitHub Pages (Hospedagem e Deploy)

### 🇺🇸 English

**Notícia Cidade** is a classic news portal project developed to consolidate fundamental web structuring and interactivity knowledge. It combines a traditional grid layout with modern navigation and media display features.

View the project live: [https://lukasmaicon.github.io/Noticia-Cidade/](https://lukasmaicon.github.io/Noticia-Cidade/)

### Interactive Development

This project is built focusing on responsive design best practices and dynamic elements manipulation. I leverage these strategies to:

* **Menu Interactivity:** Using JavaScript to create a fluid navigation experience on mobile devices.
* **Image Gallery:** Inclusion of a dynamic visual section using the jQuery library, enriching the informative layout.
* **Responsiveness:** Fully adaptable layout via Media Queries, prioritizing readability on smaller screens.

### Technologies

* HTML5 (Semantic structuring)
* CSS3 (Media Queries)
* JavaScript (Vanilla)
* jQuery (Interactive gallery)
* GitHub Pages (Hosting and Deploy)
